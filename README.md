# Quiz App

An interactive quiz application built while learning advanced React patterns — component composition, state management, and conditional rendering.

## Built With

![React](https://img.shields.io/badge/React_19-61DAFB?style=flat-square&logo=react&logoColor=black)
![Vite](https://img.shields.io/badge/Vite-646CFF?style=flat-square&logo=vite&logoColor=white)

## Features

- Multiple-choice quiz flow with question navigation
- Score tracking
- Instant feedback on answer selection
- Built with functional components and React hooks

## Getting Started

```bash
# Clone the repo
git clone https://github.com/FareenaAkram/quiz-app.git
cd quiz-app

# Install dependencies
npm install

# Run locally
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

## About This Project

This was built as part of my hands-on practice with advanced React concepts. It focuses on clean component structure and state handling without external state libraries.
